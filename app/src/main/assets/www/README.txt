Мои биоритмы v2.0 — автономная HTML/PWA версия для Android.
Откройте index.html в браузере. Для установки PWA как приложения разместите папку на HTTPS-хостинге и откройте адрес в Chrome -> Установить приложение.
Сохраняются сон, дневник самочувствия, покерные и спортивные сессии, статистика 7/30 дней. Данные остаются в localStorage браузера; экспорт JSON через История -> Экспорт JSON, импорт через Настройки.
При обновлении с v1 сохранится история при условии того же origin (адреса сайта): ключ хранилища сохранён my_biorhythms_v1.
Это не APK. Автоматическая синхронизация COROS отсутствует. График бодрости приблизительный, не медицинское измерение.
