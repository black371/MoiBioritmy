Как получить APK без Android Studio:
1. Создайте пустой репозиторий на github.com.
2. Загрузите в корень репозитория содержимое этого архива (включая папку .github).
3. Откройте вкладку Actions -> Build Android APK -> Run workflow.
4. Дождитесь зелёной отметки, откройте запуск и скачайте артефакт MoiBioritmy-Android-APK.
5. Распакуйте скачанный ZIP. Внутри app-debug.apk — установочный файл для Android.
6. Откройте APK на телефоне и разрешите установку из этого источника, если Android попросит.

Это debug APK, подписанный автоматически для тестирования. Сборка не была выполнена в текущей среде.
